# 교재

`Infineon_FAE_Expert_Integrated.html`은 교재 「Infineon FAE · 기초 + 현업 전문가 심화 통합 v4.0」입니다. 이 앱의 실습 FL01–FL12와 EX01–EX12가 교재와 같은 ID로 연결됩니다.

- 브라우저로 직접 열 수 있습니다. 앱을 실행하면 각 실습 화면의 📖 링크가 해당 장으로 바로 열립니다(`http://127.0.0.1:8765/textbook#<장 id>`).
- 앱이 쓰는 장 링크 243개는 모두 이 파일 안에 실제로 있는 위치입니다.
- 교재 수치와 앱 계산이 다른 곳은 [docs/ERRATA.md](../docs/ERRATA.md)에 근거와 함께 적었습니다. 교재 원문은 받은 그대로 두었습니다.
