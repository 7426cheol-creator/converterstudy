# 알려진 한계 (Known limits)

이 문서는 저장소 전체에 걸친 한계를 모았습니다. 실험별 가정과 적용 불가 범위는 각 결과 화면과 [MODEL_CARDS.md](MODEL_CARDS.md)에 실행 결과 그대로 있고, 실습별 주장 한계는 [TRACEABILITY.md](TRACEABILITY.md)에 있습니다.

## 1. 무엇을 증명하지 않는가

- **하드웨어 validation은 하나도 없습니다.**
  - 모든 판정은 합성 회로 안에서 방정식을 올바르게 풀었는지 확인한 verification입니다.
  - 서로 다른 solver, 닫힌 식, Octave 사이의 일치도 numerical verification이지 실측 근거가 아닙니다.
- **실제 부품이나 제품의 성능을 말하지 않습니다.**
  - 소자, 코어, 열망, 모터, 필터 값은 교재의 합성 예이거나 ASSUMED입니다.
  - DATASHEET 출처로 표시한 값은 없습니다.
  - Infineon 제품을 합성 수치로 비교하거나 순위 매기지 않습니다.
- **다음 판정은 만들지 않습니다.** 해당 실험은 NOT_EVALUABLE, SCREEN_ONLY, MISSING_INPUT으로 남깁니다.
  - EMI 규격 적합성(EX09)
  - 단락 생존, fuse 동작, 기능안전(EX10)
  - 수명 연수(FL03, EX08)
  - 정밀 core loss(FL07, EX04)
  - 효율 향상(EX06)
- **학습 상태를 판정하지 않습니다.**
  - 시뮬레이션 PASS, 내 답, 학습 완료는 다른 필드입니다.
  - FL12와 EX12의 설명형 답은 rubric과 기록만 있고 자동 채점하지 않습니다.
  - ‘면접 준비 완료’는 어디에도 표시하지 않습니다.

## 2. 모델 수준별 한계

| 수준 | 무엇인가 | 주요 한계 |
|---|---|---|
| A 해석·FHA | 닫힌 식, 기본파 근사, 정적 해 | FHA 해는 스위칭 운전점이 아닐 수 있다(ERRATA F-001, F-002). 경부하와 f_r 아래의 불연속 정류에서는 틀린다(FL09 `below_heavy`는 +24.4 % 차이로 OUT_OF_VALIDITY) |
| B 평균 동역학 | 주기 평균 상태방정식, 소신호 | 리플·샘플링·스위칭 고조파가 없다. 평균모델에 리플을 덧그려 스위칭 모델처럼 보이게 하지 않는다 |
| C 이상 스위칭 | 구간 선형 회로의 정확한 해(행렬지수와 사건 탐지) | 스위치·다이오드가 이상적이라 ZVS는 NOT_EVALUABLE(부호·전하 screen만 SCREEN_ONLY)이다. 링잉, 역회복, gate 동역학이 없다 |
| D 비이상 commutation | 합성 C(v), 합성 DPT 셀, 합성 병렬 branch | vendor 소자 모델이 아닌 경향 실험이다. 역회복·온도·패키지 기생은 범위로만 다룬다 |

## 3. 실습군별 주요 한계

- **Buck·Boost (FL01)**
  - 손실과 링잉이 없습니다.
  - RHP zero 응답은 저항부하, CCM, duty 입력 조건에서만 성립합니다.
- **소자·병렬·DPT (FL02, EX02, EX03)**
  - 손실 비교는 이상 전류 파형에 손실을 후처리한 추정입니다.
  - DPT와 병렬 동적 분담은 bounded synthetic equivalent입니다.
  - 식별할 수 없는 상호결합은 범위로만 보고합니다.
- **열·전열 (FL03, EX08)**
  - Foster 내부 노드를 실제 package 층으로 쓰지 않습니다.
  - 전열 발산은 단순 모델의 결과이지 실물 열폭주 예측이 아닙니다.
  - MC 분포와 상관은 가정입니다(seed 명시).
- **인버터·고장 (FL04, EX10)**
  - L_d, L_q, ψ_m은 선형입니다(포화·교차결합 없음).
  - freewheel은 비돌극 근사입니다.
  - 보호 시간과 단락 내량은 합성 학습 값입니다.
- **PFC·제어·안정도 (FL05, FL06, EX07)**
  - 강제 정현파 모델의 THD = 0은 PFC 성능이 아닙니다.
  - 이상 CPL 결과는 무한대역 국소 해석입니다.
  - 컨버터 입력 임피던스는 평균 소신호 모델이며 실측 임피던스가 아닙니다.
- **자성체·변압기 (FL07, EX04)**
  - 코어는 선형입니다(포화·히스테리시스 없음).
  - Steinmetz 계수와 Dowell R_ac는 합성입니다.
  - 식별 회로의 권선 capacitance는 집중 근사입니다.
- **DAB (FL08, EX06)**
  - width candidate는 격자 탐색 결과이며 global optimum이 아닙니다.
  - RMS 감소를 효율 이득으로 바꾸려면 손실 모델과 그 출처가 필요합니다.
- **LLC·CLLC (FL09, FL10, EX05)**
  - 정류기는 이상 다이오드입니다.
  - 출력은 강성 배터리 또는 합성 R-C입니다.
  - 기동과 역방향은 합성 시나리오입니다.
  - plant-only Floquet 승수는 폐루프 안정성이 아닙니다.
- **PSFB (FL11)**
  - 48 V seed(n = 12, 800 V, D_eff 0.72)와 L_k, L_o, 경로 저항은 합성입니다.
  - 자화전류, 2차 링잉, SR 타이밍 오차는 계산하지 않습니다.
- **EMI (EX09)**
  - receiver와 규격 LISN이 없는 상대 conducted-noise proxy입니다.
  - 3-level midpoint 확장(지침상 선택)은 구현하지 않았습니다.
- **불확도 (EX11)**
  - 통계 상한은 IID 가정에서만 씁니다. 결정적 grid에는 NOT_EVALUABLE입니다.
  - Monte Carlo는 분포, 상관, seed를 명시한 조건부 결과입니다.
- **사례·메모 (FL12, EX12)**
  - 시뮬레이션은 선택한 가설의 결과입니다. 실제 고객의 root cause를 확정하지 않습니다.
  - 메모의 수치는 합성 모델의 실제 실행 값입니다.

## 4. 수치 방법의 한계

- 공차는 실험마다 명시합니다. 정상상태 판정은 한 주기의 상태 변화와 에너지 잔차를 기준으로 하며 마지막 몇 주기를 잘라내는 방식이 아닙니다.
- guard 사건은 표본 탐색 뒤 brentq로 찾습니다. 한 표본 간격 안에서 두 번 교차하는 매우 짧은 구간은 놓칠 수 있습니다. 공진 실험은 독립 적분기(DOP853, 사건 탐지)와 비교해 이를 점검합니다.
- FL10 고전압 corner의 peak 위 운전점은 dP/df가 약 −1.63 kW/Hz입니다(이상 무손실 모델). 이 근처의 수치는 주파수 1 Hz 단위로 민감하며, 실제 회로에서는 손실·지연·제어가 이 민감도를 바꿉니다.
- 전체 기준 실행(`run-all`, 189회)은 이 환경에서 약 150 s 걸립니다. 공진 주기해와 EX11 메타 실험이 가장 느립니다.
- 작은 행렬의 행렬지수는 BLAS 스레드 경쟁에 매우 약해서 패키지가 `OPENBLAS_NUM_THREADS=1` 등을 기본으로 정합니다. numpy를 먼저 import하는 외부 스크립트는 환경변수를 직접 정해야 합니다.

## 5. 도구·자료의 한계

- **원본 패키지가 없습니다(ERRATA E-000).** 계약과 기준값은 지침·교재 본문에서 재구성했습니다. 원본 `simulation_contract_v4.json`, `reference_results.json`, v3 baseline과의 정합은 확인하지 못했습니다.
- **MATLAB/Simulink/Simscape와 PSIM 12.0.2는 이 환경에 없어 실행하지 않았습니다(NOT_RUN_ENVIRONMENT).**
  - Simscape builder의 블록 lookup과 `_specify` 파라미터 이름은 실제 MATLAB에서 검증되지 않았습니다.
  - PSIM build sheet는 수동 재구성용입니다.
- **Octave 교차검증 범위.** 교재 식으로 다시 쓴 일부 대표점(DAB, EX02, EX06, EX07, FL01, FL05, FL09, CLLC FHA)만 다룹니다. 모든 실험을 복제하지 않습니다.
- **브라우저.** 스모크 테스트는 Chromium(Playwright)에서만 돌렸습니다.
- **교재 파일.** 교재 HTML은 공개 저장소라서 커밋하지 않았습니다. 교재 링크는 사용자가 `textbook/`에 파일을 둘 때만 열립니다.

## 6. 사용 환경의 한계

- 한 사람이 자기 컴퓨터에서 쓰는 로컬 앱입니다. 인증이 없으므로 127.0.0.1 밖으로 열지 마세요.
- 학습 기록은 `~/.convlab/progress.json` 하나에 저장됩니다. 백업은 ‘내 기록 → JSON으로 내보내기’로 합니다.
- 한 실행 요청은 서버에서 동기적으로 계산됩니다. 느린 실험(공진 주기해, EX11 메타)은 수 초에서 수십 초 동안 화면이 기다립니다.
